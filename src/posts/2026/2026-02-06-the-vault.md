A quick reference of snippets and workflows I use often in Houdini. Bookmark or search as needed.

## VEX

### Camera cull

Camera cull in VEX. Add a string parameter `cam` (operator path to your camera) and a float `buf` for margin. Points outside the camera frustum or behind the camera are removed.

```vex
string cam = chs("cam");
float buf = ch("buf");
vector ndc = toNDC(cam, @P);
if (ndc.x < -buf || ndc.x > (1+buf) || ndc.y < -buf || ndc.y > (1+buf) || ndc.z > 0) {
    removepoint(geoself(), @ptnum);
}
```

### Looping value from 0–1

```vex
@timeloop = (@Time % 2) / 2;
```

### Attribute from other input

Read an attribute from another input (e.g. input 2, `@P`).

```vex
@P = point(1, "P", @ptnum);
```

### Centroid

Houdini has a built in centroid function, and also a centroid node. Use whichever you prefer.
centroid function is used like this.

```vex
centroid(surface_node, type)
Example: centroid(0,0) centroid(0,1) centroid(0,2)
```

### Using point() expression

In a Houdini expression (not VEX), get a component of a point’s position. Arguments: geometry path, point number, attribute, component index. Fourth argument is axis: 0 = X, 1 = Y, 2 = Z.

```
point("geometry_path", 0, "P", 0)  // X
point("geometry_path", 0, "P", 1)  // Y
point("geometry_path", 0, "P", 2)  // Z
```

### Delete points based on colour

Delete points where colour is below a threshold (e.g. dark areas). Uses `length(@Cd)` so it works for any colour; add a spare float parameter `threshold`.

```vex
if (length(@Cd) < ch("threshold")) {
    removepoint(0, @ptnum);
}
```

### Delete points with slider

Random delete with threshold and seed. Use `@id` instead of `@ptnum` if you have stable id attributes.

```vex
if (rand(@id * ch('seed')) < ch('threshold')) {
    removepoint(0, @ptnum);
}
```

### Group points with slider

```vex
if (rand(@ptnum) > ch('threshold')) {
    i@group_mygroup = 1;
}
```

### Probability based attribute

Randomly assign 1 or 0 based on probability. Normalized 0–1 (0.5 = 50% chance). Add float parameters `probability` and `seed`.

```vex
float prob = chf("probability");
float seed = chf("seed");

// rand() returns value between 0.0 and 1.0
float random_val = rand(@ptnum + seed);

// Assign 1 if random value is below threshold, 0 otherwise
i@trigger = (random_val < prob) ? 1 : 0;
```

### Rotate @orient around an axis

Rotate `@orient` around an axis. Use a spare float `rot` (angle in radians). `set(0, 1, 0)` is the axis (here, Y). Signature is `quaternion(angle, axis)`.

```vex
vector4 rot = quaternion(ch("rot"), set(0, 1, 0));
@orient = qmultiply(p@orient, rot);
```

### Remap value to custom range

VEX version of `fit()` for remapping values. Useful for normalizing attributes or creating custom falloffs.

```vex
// Remap @Cd.r from 0-1 to 0.2-0.8
@Cd.r = fit(@Cd.r, 0, 1, 0.2, 0.8);

// Remap @P.y from bounding box to 0-1
vector bbox_min = getbbox_min(0);
vector bbox_max = getbbox_max(0);
@ramp = fit(@P.y, bbox_min.y, bbox_max.y, 0, 1);
```

### Create @N from velocity

Orient instances using velocity direction. Perfect for copy to points when you have velocity but no normals.

```vex
@N = normalize(@v);
// Optional: add up vector for stable rotation
@up = {0, 1, 0};
```

### Random color by ID

Quick color visualization for debugging. Each piece/ID gets a unique random color.

```vex
@Cd.r = rand(@id);
@Cd.g = rand(@id + 1);
@Cd.b = rand(@id + 2);
```

### Smooth attribute with neighbors

Average an attribute using neighboring points. Add integer parameter `iterations` to control smoothing strength.

```vex
int iterations = chi("iterations");
for (int i = 0; i < iterations; i++) {
    int neighbors[] = neighbours(0, @ptnum);
    float sum = 0;
    foreach (int n; neighbors) {
        sum += point(0, "P", n).y; // Change to any attribute
    }
    @P.y = sum / len(neighbors);
}
```

### Quick noise patterns

Common noise setups for procedural variation. One-liners you'll use constantly.

```vex
// Basic position noise
@P += noise(@P * ch("freq")) * ch("amp");

// Animated noise with time
@P.y += noise(@P * ch("freq") + @Time * ch("speed")) * ch("amp");

// Curl noise for natural flow
@v = curlnoise(@P * ch("freq") + @Time);

// ID-based variation (no animation)
@pscale = fit01(rand(@id), 0.5, 1.5);
```

## Expressions

### Automatic filepath

Output path that stays organized. Uses a `ver` integer parameter so you can bump version and keep old caches.

```
${JOB}/geo/${OS}/v`padzero(3, chsop("ver"))`/${OS}.${F}.bgeo.sc
```

### Fit expression in Carve SOP

Animate carve along a curve over time (e.g. in First U or similar).

```
fit($F, $FSTART, $FEND, 0, 1)
```

General form: `fit(num, oldmin, oldmax, newmin, newmax)`.

### Get output from opinputpath

Resolve a connected input: `0` = first input, `1` = second, etc.

```
`opinputpath("..", 0)`
```

### bbox and centroid

For pyro/smoke container: use **Size** and **Center** with bbox and centroid. Axis: bbox uses 6=X, 7=Y, 8=Z; centroid uses 0=X, 1=Y, 2=Z.

```
bbox("inputPathToBounding", 6)
centroid("inputPathToBounding", 0)
```

### Channel reference types

Different channel functions for different data types. Using the right one prevents type conversion issues.

```
ch("parmname")   // Float (most common)
chi("parmname")  // Integer
chs("parmname")  // String
chv("parmname")  // Vector (returns 3 floats)
```

### Relative vs absolute paths

Reference other nodes in expressions. Relative paths are more flexible when duplicating networks.

```
// Relative (from current node)
ch("../transform1/tx")
ch("../../null1/parm")

// Absolute (from root)
ch("/obj/geo1/transform1/tx")

// Reference input's parameter
ch("`opinputpath('..',0)`/parm")
```

## Tips

### Connecting detached curves

To fuse splines into one primitive, use the **PolyPath** SOP (spline fuse). It turns edges into polygon curves that stop at branch points, deduplicates edges, and can clean up topology. Handy for merging detached curve segments.

### HDA namespace and versioning

Use a namespace and version so Houdini loads the right asset and you don't overwrite older instances.

- **Operator name:** `AFX::renderkit::1.0`
- **Operator label:** `renderkit`

Keeps versioning and avoids missing HDAs when opening old scenes. [SideFX: namespaces](https://www.sidefx.com/docs/houdini/assets/namespaces).

### Attribute promote methods

When to use each promotion method in Attribute Promote SOP:

- **Maximum** - Get highest value (e.g., max velocity in a piece)
- **Minimum** - Get lowest value
- **Average** - Smooth/blend values (most common for point→primitive)
- **Sum** - Add all values together
- **First Match** - Take first point's value (fast, deterministic)
- **Last Match** - Take last point's value

**Tip:** For packed primitives, promote point attributes to primitive first, then pack. Attributes on points inside packed geo aren't accessible.

### Group expressions

Quick patterns for grouping in Group SOP or Blast SOP. Set **Group Type** to "Guess from Group" and use expressions in the **Group** field.

```
@P.y > 0              // Points above origin
@Cd.r > 0.5           // Red channel above threshold
@id % 2 == 0          // Every other piece (even IDs)
rand(@ptnum) < 0.3    // Random 30% of points
piece*                // All groups starting with "piece"
!group_name           // Invert group (everything NOT in group)
```

### Visualizer presets for debugging

**Geometry Spreadsheet** (Alt+Shift+G) is great, but visualizers are faster during iteration:

1. Select geometry node → **RMB** → **Visualize** → pick attribute
2. Or create **Attribute Visualize SOP** for persistent preview
3. **Scene View** → Display Options (D) → **Markers** to see normals/velocity/other vectors

**Common visualizations:**
- `@Cd` - See point colors
- `@N` - Check normal directions (shows as arrows)
- `@pscale` - Verify scale variation (shows as circles)
- `@v` - Visualize velocity/direction

### Copy to Points orientation

Standard setup for oriented instances with Copy to Points. Template points (first input) need these attributes:

```vex
// Minimal setup - just normals
@N = {0, 1, 0};  // Or use velocity: @N = normalize(@v);

// Full control - normals + up vector
@N = {0, 1, 0};
@up = {0, 0, 1};

// Advanced - use quaternions for precise rotation
@orient = quaternion(maketransform(@N, @up));
```

**Copy to Points reads these attributes (in priority order):**
1. `@orient` (quaternion) - most precise
2. `@N` + `@up` (vectors) - common method
3. `@N` + `@pscale` + `@rot` - basic method
4. Transform matrix - rarely used

### Quick keyboard shortcuts

Workflows that save hours over time:

- **Alt + LMB drag** - Frame selected geometry
- **H** - Home all (frame everything)
- **G** - Show/hide grid
- **D** - Display options
- **Alt + Shift + G** - Geometry spreadsheet
- **Shift + W** - Wireframe shaded toggle
- **Shift + G** - Ghost other objects
- **Ctrl + Shift + C** - Node palette search
- **X** (in viewport) - Quick radial menu for common tools
